GIGSY — RUN EVERYTHING

1. Extract the ZIP.
2. Open PowerShell in the extracted gigsy_chroma_work folder.
3. Run these commands:

Set-ExecutionPolicy -Scope Process Bypass -Force
.\RUN_GIGSY.ps1

The launcher checks Node.js, Python and MySQL, starts a detected MySQL Windows service,
installs the project dependencies/configures secrets if needed, starts ChromaDB and Next.js
in separate PowerShell windows, checks the MySQL API health endpoint, and opens the app.

Required software:
- Node.js 22 LTS
- Python 3.11 or 3.13, 64-bit, with the Python launcher (py)
- MySQL Server 8.x, running locally, with the existing Gigsy database/schema
- Internet for first-time package installation and the initial Sentence Transformers model download

URLs:
- App: http://localhost:3000
- MySQL API health: http://localhost:3000/api/health
- Chroma service health: http://localhost:8001/health

If the MySQL API check fails, check DB_HOST, DB_PORT, DB_USER, DB_PASSWORD and DB_NAME in .env.local.
The database schema is expected to be the existing Gigsy schema; this source ZIP does not contain a
full database schema migration. Do not delete or recreate your existing database.
Keep both service windows open. Do not commit .env.local or semantic_service/.env.
